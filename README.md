# 7주차 과제

## 프로젝트 소개

- 서비스: [보카블릿]
- 주요 사용자: [ 사이트에 처음 접속하여 사용하려는 사용자 ]
- 핵심 행동: [ 회원가입과 로그인, 이후 사이트에서 단어를 기록 및 복습 ]

## 사용자 흐름

소개 페이지 읽기 -> [시작하기] -> 간단 가입 -> 자동 로그인 -> 온보딩(학습 언어, 닉네임) -> 첫 카드 등록 -> 첫 복습 체험

로그인 -> 홈(오늘 복습할 카드 N장) -> 복습 세션 -> 완료 화면

언제든 단어 등록 페이지/단어장 목록 접근

## 분기 시나리오

# 소개 페이지

1. 소개 페이지를 읽음(스크롤 다운)
2. 로그인 페이지로 향하는 버튼을 누른다
3. 페이지를 로그인 페이지로 리다이렉트

- 소개 페이지를 읽음(스크롤다운)
- 서비스를 시작하기 위한 두 종류의 버튼
  - [시작하기]: 회원가입 페이지로 이동(신규 사용자)
  - [로그인]: 로그인 페이지로 이동 (기존 사용자)
- 이미 로그인한 사용자가 접속하면 메인 서비스 화면으로 바로 리다이렉트

# 로그인 페이지

1. 아이디/비밀번호 입력 후 로그인
2. 하단에 회원가입 버튼

성공시 홈으로 이동

# 회원가입 페이지

입력 항목: 아이디, 이메일, 비밀번호, 비밀번호 확인, 약관 동의

1. 아이디 입력->중복확인->사용 결정
   - 아이디 중복 확인: 중복 확인 버튼을 누르면 중복 여부에 따라 레이블 텍스트로 알려주기
   - 아이디 형식: 인풋 박스 벗어날 때 하단 레이블로 맞는 양식인지 대조
   - 필드가 비어있음: 입력 요청, 포커스
   - 아이디가 조건을 미충족: 인풋값 실시간 대조
2. 비밀번호 입력 및 재입력 통한 검토
   - 비밀번호 검증용 재입력과의 불일치: 실시간 인풋 이벤트로 대조
   - 비밀번호 자체의 보안 등급:실시간으로 비밀번호 강도를 보여주기
3. 약관 읽고 확인

# 단어 학습 페이지

0. 오늘 복습할 단어
   - 복습할 단어카드 프리뷰
   - 복습 시작 버튼
   - 빈 상태일 시 [첫 단어 등록하기]
1. 새로운 단어 등록
   - 새로운 카드 등록 버튼 누르기
   - 카드에 필요한 정보들을 입력
   - 적은 사항들을 submit해서 카드로 등록
2. 등록된 단어 관리/수정
   - 기존 카드들의 목록 페이지
   - 수정 버튼
   - 입력란에 기존 데이터가 나타난다....
   - 수정완료

### 단어카드의 구성품

1. 단어 원문(필수)
2. 단어 뜻(필수)
3. 단어 예문(선택기입)
4. 단어의 품사(선택)(라디오버튼 등으로 구현)
5. 단어의 변형이 있는 경우(단수형-복수형, 문법적 성별 등) 연결되는 하위 객체로 생성-연결 가능하게 하기(선택기입)

## 입력흐름

1. 새 단어 등록 버튼 클릭
2. 필수 입력란을 채우면 저장 버튼이 활성화
3. 저장 버튼을 클릭하여 카드로 등록
4. 저장 실패 시 입력 내용 유지, 저장이 되지 않았음을 띄워준다
5. 뒤로 가기 누를 시 팝업으로 "단어를 저장하지 않고 돌아갑니까?" 메세지 팝업(yes/no)

## 단어장 목록/카드 관리

- 등록 카드 목록 표시
- 수정 버튼>기존 데이터 입력란>수정완료
- 삭제: 버튼을 누르면 재확인 팝업이 뜬다 "정말로 삭제하시겠습니까?"

### 카드 구성

- 앞면: 단어 원문
- 뒷면: 뜻 + 예문 + 품사 (+문법적 변형 함께 표시)
- 클릭/탭 시 뒤집기 가능
